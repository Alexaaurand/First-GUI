# First GUI - Java Choice Assistant

A Java Swing application that helps users make a random choice from a list of options. I built this project while learning Java to practice turning basic programming concepts into an interactive graphical application.

## Features

- Add choices to a list
- Remove choices from the list
- Randomly select one of the entered choices
- Prevent invalid user input
- Display the selected choice in the GUI

## What I Practiced

- Java Swing
- ArrayLists
- If/else statements
- Event handling
- User input validation
- Random selection
- Building a GUI (graphical user interface)

## About This Project

This is one of my first Java GUI projects. I created it as a way to apply the Java concepts I was learning to a program that someone could actually interact with.
